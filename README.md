# 指南山腳下 Beneath Mount Zhinan

動物園大學的四年人生模擬器。你選學院與科系、排課表、打工、社團、談戀愛、出國交換，最後在畢業時挑一條路。每條路都可能失敗，但不管結果如何，都會拿到一張屬於你的畢業結算圖和一段日後談。

這是我用 Claude 以 Vibe Coding 做出來的作品，專為手機設計，打開網頁就能玩。

## 玩法

一局共 16 個時段，每學年依序是上學期、寒假、下學期、暑假。

- **學期中**：自己選課（涼課、普通、硬課各有取捨）、安排這學期要做的事、面對隨機事件、考期中與期末。
- **假期**：選擇怎麼度過，打工存錢、旅行、回家，或買機車、筆電、相機等物品。
- **大二、大三**：可以報名出國交換。
- **大四**：準備推甄、國考，或投履歷。
- **畢業**：先過畢業審查，再從十四種職涯中挑一條路，最後看結算與日後談。

## 特色

- **六項能力**：學業、專業、外語、社交、才藝、體能，會隨選擇成長，越高成長越慢。
- **完整的課程系統**：依必修、群修、通識、體育與選修排課，有重修、擋修與選課季的額滿事件。
- **人際與感情**：室友、直屬學長姊、導師、朋友與心動對象，各有專屬事件。也有復合、遠距離戀愛與跨國戀。
- **打工與社團**：四種打工、五種社團，可以當幹部、選社長。
- **Seed 機制**：相同 Seed 加上相同選擇，就會走出相同的人生，可以和朋友並排比較。
- **成就牆**：30 個成就，跨局保存在你的瀏覽器，可匯出與匯入。
- **存檔碼**：自動存檔，也能複製存檔碼到別的裝置繼續玩。
- **深色模式**：預設跟隨裝置，可手動切換。
- **可加入主畫面**：支援 PWA，加入 iPhone 主畫面後可全螢幕遊玩。

## 視覺設計

介面走大學校園風，每個元件都對應一樣校園裡的實物：狀態列是教室黑板，卡片是釘在公佈欄上的紙，事件選項是答案卡的 A、B、C、D，判定結果是蓋在紙上的章，成績是一張成績單。首頁是紅磚鐘塔校舍、指南山纜車與操場跑道的插畫，深色模式會變成亮著燈的夜晚校園。圖示使用 [Phosphor Icons](https://phosphoricons.com)（MIT 授權）。設計規格與改版過程記錄在 [`DESIGN-SPEC.md`](./DESIGN-SPEC.md)。

## 在本機執行

不需要安裝任何東西。下載專案後，直接用瀏覽器開啟 `index.html` 即可。
